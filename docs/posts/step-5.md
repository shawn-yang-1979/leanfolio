# Step 5 - 設定定時定額

請盡量使用定時定額累積你的投資目標.

以我個人為例, 以下三部分我都是使用定時定額的方式持續買進:

- 40.0% 0050 TISA
- 15.0% VT.US
- 07.5% Gold

## 0050 TISA

```
Given
未來 5 年可投入總金額 = 8,000,000
此項投資組合比例 = 40%
未來 5 年可投入此項投資組合金額 = 8,000,000 X 40% = 3,200,000

When
每次定時定額 6,000 TWD
每個月扣款 9 次
持續買進 5 年 = 6,000 TWD X 9 X 12 X 5 = 3,240,000 TWD
3,240,000 TWD, 略高於 3,200,000 TWD.

Then
每次定時定額 6,000 TWD
每個月扣款 9 次
```

## VT.US

```
Given
未來 5 年可投入總金額 = 8,000,000
此項投資組合比例 = 15%
未來 5 年可投入此項投資組合金額 = 8,000,000 X 15% = 1,200,000
以 1 美元約 30 台幣估算, 1,200,000 TWD 約等於 40,000 USD.

When
每次定時定額 75 USD
每個月扣款 9 次
持續買進 5 年 = 75 USD X 9 X 12 X 5 = 40,500 USD
40,500 USD, 略高於 40,000 USD.

Then
每次定時定額 75 USD
每個月扣款 9 次
```

## Gold

```
Given
未來 5 年可投入總金額 = 8,000,000
此項投資組合比例 = 7.5%
未來 5 年可投入此項投資組合金額 = 8,000,000 X 7.5% = 600,000

When
每次定時定額 5,000 TWD
每個月扣款 2 次
持續買進 5 年 = 5,000 TWD X 2 X 12 X 5 = 600,000 TWD
600,000 TWD 等於 600,000 TWD.

Then
每次定時定額 5,000 TWD
每個月扣款 2 次
```
