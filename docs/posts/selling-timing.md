# 賣出策略

## 果樹理論
你的資產就是果樹, 你就是果農. 

你投入心力挑選最好的樹苗, 每天照顧果樹, 定時投入肥料, 期望果樹能夠成長茁壯. 10 年後果樹長大了開始結果, 往後每年你都會有收穫, 而且隨著果樹越長越高, 你的收穫也越來越高.

大部分的果農犯的最嚴重錯誤只有這兩個:
 - 樹苗挑錯
 - 砍了優質果樹當柴燒

思慮正常的果農不可能因為果樹長高了就把樹砍了拿去當柴賣掉, 但你還是應該在適當的時機對它做適當的修剪. 

假設你有 20 棵果樹, 其中 3 棵果樹最近突飛猛進, 長得特別高, 以至於你大部分的收成也都來自這 3 棵果樹. 這樣的狀態是有風險的. 假如哪天打雷劈掉了你其中一棵產量最大的果樹, 你的收成就會瞬間大幅減少. 因此, 讓所有果樹都依據你設定的成長目標均衡地發展是非常重要的.

身為一個專業果農, 你會在適當的時機修剪過高的枝幹. 修剪下來的枝葉還可以堆肥, 平均的分配到每棵果樹下, 讓每棵果樹均衡地發展.

只有一種狀況你會直接砍掉整顆果樹: 這顆果樹已經老了, 病了, 未來的產量只會越來越少. 而且你找到更好的品種取代這棵果樹. 

這時候你就可以先種下新樹苗, 然後選擇適當的時機把這棵老樹砍了. 你不可能馬上砍了這棵老樹, 因為它還是有產量. 你會在適當的時機讓他退場, 例如: 在這棵老樹剛好生了一場大病的時候放棄救治, 直接砍了他.

## 賣出條件
你是否曾經賣掉 200 多的台積電, 然後幾年後看到他漲到 2000? 標準散戶心路歷程.

賣出資產的意義其實只是把你的資產轉換成另一種資產. 散戶失敗的地方就是很喜歡把賺錢的資產轉換成不賺錢的資產, 例如: 把 0050 轉換成 Cash.

本投資策略設定了兩條嚴格的賣出條件, 必須符合以下兩種條件之一, 你才可以擇時賣出你的資產:
1. 你的投資組合中已經不打算保留這項資產. 你的樹老了, 病了, 而且你找到了品種更好的新樹苗取代它.
2. 這項資產嚴重超出既定資產配置比例, 需要再平衡. 你的樹太高了, 需要適當的修剪.

> 再平衡 (Rebalancing) 是指在投資理財中, 當市場價格波動, 導致你原本設定的資產配置比例發生偏離時, 透過賣出漲多變重的資產, 買進跌落變輕的資產, 把比例調整回最初規劃的狀態.

## 資產配置上限
要不要執行再平衡? 你需要先定義什麼叫做 "嚴重超出既定資產配置比例". 

如果要你每天都盯著你當前各資產項目佔總資產的比率是否有偏移你既定的投資組合比例, 這樣會很累也沒有必要. 你應該做的是幫你每項資產設定一個金額上限, 超過那個上限就進入你的雷達範圍.

這時候你的投資目標以及投資組合比例就派上用場了. 你只要依據你的投資目標, 乘上你的投資組合比例, 就可以當作你的各項資產配置的上限.

換句話說, 如果你某個資產項目根本還沒達到你預定的投資目標, 你根本就不需要煩惱該不該賣, 根本不該賣. 唯有你某個資產項目嚴重超過你既定的投資目標時你才需要考慮什麼時候賣.

假設你的投資目標是 100K 美金, 搭配投資組合比例就可以得到資產配置上限如下:

| 資產項目   | 投資組合比例 | 資產配置上限 |
|-----------|------------:|------------:|
| Gold      |       7.50% |       7,500 |
| Dollar    |       7.50% |       7,500 |
| VT        |         15% |      15,000 |
| 0050 TISA |         40% |      40,000 |
| 台積電     |          3% |       3,000 |
| 鴻海       |          3% |       3,000 |
| 富邦金     |          3% |       3,000 |
| 國泰金     |          3% |       3,000 |
| 廣達      |          3% |       3,000 |
| 中信金     |         3% |        3,000 |
| 聯發科     |          3% |       3,000 |
| 台達電     |          3% |       3,000 |
| 日月光投控 |          3% |       3,000 |
| 台新新光金 |          3% |       3,000 |
| **Total** | **100.00%** | **100,000** |

假設最近台積電暴漲, 你已經累積了超過了 3,000 美元的台積電股票, 這時候你才需要觀測適當的賣出時機. 賣出時機出現時, 你也只需要讓台積電回到 3,000 美元以下的水位即可, 切勿多賣.

## 觀測方法
前提: 你已經有資產項目符合賣出條件

觀測頻率: 每日

觀測指標: 還原月 KD

例如:
- 你已經發現你的台積電符合再平衡條件, 每天中午 13 點飯後, 觀測一次還原月 KD, 若符合賣出的交易規則, 則賣出部分持股, 讓台積電回到其資產配置上限以下.
- 你已經決定把兆豐金踢出你的投資組合, 每天中午 13 點飯後, 觀測一次還原月 KD, 若符合賣出的交易規則, 則將兆豐金出清.

## 交易規則
交易規則只有兩條.

Rule 1
```
Given:
出現轉折向下 pattern

When:
本次還原 K 指標在 80 以上
And
出現死亡交叉 pattern

Then:
賣出
```

Rule 2
```
Given:
出現轉折向下 pattern

When:
本次還原 K 指標在 20-80 之間

Then:
賣出
```

每個轉折只買一次. 不要 Rule 1 買了一次, 過幾天 K 進入 20-80 區間符合 Rule 2, 又再買一次.
